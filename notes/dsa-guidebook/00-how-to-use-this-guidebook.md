# How to use this guidebook

This guidebook covers three famous DSA question lists. It gives you hints and a way of thinking for each question. It does NOT give full answers, on purpose: you learn by solving.

## The three lists

| List | Questions | Easy | Medium | Hard |
|---|---|---|---|---|
| NeetCode 150 | 150 | 28 | 101 | 21 |
| NeetCode 250 | 250 | 60 | 155 | 35 |
| Striver A2Z sheet | 474 | 152 | 186 | 136 |

- NeetCode 250 = all of NeetCode 150 plus 100 more (mostly easier warm-up questions). There is no "NeetCode 350"; the official lists are 75, 150 and 250.
- The Striver A2Z sheet is a full course: it also counts learning items such as "Input Output" or "What is a linked list", not only questions.
- 122 Striver A2Z questions are the same LeetCode question as one in NeetCode 250, so one set of hints serves both.

## What Easy, Medium and Hard mean

- **Easy:** one idea, usually one loop or one data structure. Aim: 15 to 20 minutes.
- **Medium:** one pattern you must recognise, plus careful details. Aim: 30 to 40 minutes. Most interview questions are Medium.
- **Hard:** two patterns combined or one clever insight. Skip these until the Easy and Medium ones of that topic feel comfortable.

## How to work on one question

1. Read the question on LeetCode. Do the given examples by hand on paper.
2. Try for 15 to 20 minutes with no help. Say the brute force out loud, even if it is slow.
3. Still stuck? Read only **Notice** in this guidebook. Try 10 more minutes.
4. Still stuck? Read **First step**. Try 10 more minutes.
5. Still stuck? Read **If stuck**. This is the main idea, but you still write the code yourself.
6. If that is not enough, watch the NeetCode or Striver video for that question, close it, and write the code from memory.
7. Solve the same question again after 3 days and after 1 week without looking. This is where it actually sticks.

## Suggested order for a beginner

1. Go chapter by chapter in the order below. Before each chapter read its "idea" and "thinking steps" sections.
2. In each chapter do all Easy questions first, then the Medium ones marked 150.
3. Leave Hard questions and the DP / Advanced Graphs chapters for a second round.
4. If a chapter feels impossible, do the matching Striver A2Z step first (files 19 and 20): Striver starts from zero and builds up slowly.

## Where the data came from

- NeetCode 150 flags and LeetCode numbers: the official neetcode-gh/leetcode repository on GitHub.
- NeetCode 250 list and difficulties: two independent copies of the neetcode.io list, which matched exactly.
- Striver A2Z: the takeUforward A2Z sheet data (step order, names, difficulties).
- Hints and thinking steps: written for this guidebook.
